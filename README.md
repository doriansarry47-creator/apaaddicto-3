# Apaaddicto 3 - Digital Wellness App

A comprehensive digital wellness application that helps users manage their app usage, reduce screen time, and build healthier relationships with technology.

## Features

### 🏠 Modern Homepage
- Clean, responsive design with gradient hero section
- Feature showcase with icons and descriptions
- User statistics and testimonials
- Quick action cards for easy navigation

### 📊 Comprehensive Dashboard
- Real-time usage statistics and trends
- App usage breakdown with visual progress bars
- Goal tracking with progress indicators
- Time filter options (Today, Week, Month, Year)
- Color-coded progress tracking

### 👤 User Profile Management
- Editable user information
- Usage statistics overview
- Achievement tracking
- Personal progress metrics

### ⚙️ Advanced Settings
- **Notifications**: Push notifications, break reminders, weekly reports
- **App Usage**: Daily limits, auto-break mode
- **Appearance**: Theme selection, language preferences
- **Privacy**: Data collection preferences
- Custom toggle switches and form controls

### 🔐 Modern Authentication
- Clean login interface with form validation
- Social login options (Google, Apple, Facebook)
- "Remember me" functionality
- Forgot password flow

### 🎨 Professional Design System
- Consistent color palette with gradients
- Modern typography using Inter and Roboto fonts
- Smooth animations and transitions
- Responsive grid layouts
- Custom styled components

## Technology Stack

- **React 19** with modern hooks
- **React Router v7** for navigation
- **Custom CSS-in-JS** styling
- **Responsive design** principles
- **Modern JavaScript** (ES6+)

## Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn package manager

### Installation

1. Clone the repository
```bash
git clone https://github.com/doriansarry47-creator/apaaddicto-3.git
cd apaaddicto-3
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm start
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

### Build for Production

```bash
npm run build
```

## App Structure

```
src/
├── App.js              # Main application component with routing
├── Navigation.js       # Navigation bar component
├── HomePage.js         # Homepage with features and stats
├── DashboardPage.js    # Analytics and usage dashboard
├── ProfilePage.js      # User profile management
├── SettingsPage.js     # App settings and preferences
├── LoginPage.js        # Authentication interface
├── NotFound.js         # 404 error page
├── theme.js            # Design system and theme
├── index.js            # Application entry point
└── index.css           # Global styles and resets
```
